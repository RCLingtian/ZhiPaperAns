# 纸条答案 · Lite版

一个轻量、简洁的在线试卷与作业答案展示系统。

本项目以原生 HTML、CSS、JavaScript 与 PHP 构建，不依赖大型前端框架，适合个人服务器部署、学习研究以及对网页答题/资料展示系统进行二次开发。

## 项目简介

「纸条答案 · Lite版」主要用于整理和展示试卷、作业等学习资料。项目采用较为简单的文件存储结构，通过 JSON 保存资料索引，由前端动态读取并生成资料列表；PHP 负责资料上传、分类识别及删除等服务端操作。

项目定位为 Lite 版本，重点是保持部署简单、结构清晰和运行成本低，不需要数据库即可完成基本功能。

## 功能

- 试卷 / 作业资料列表展示
- 资料名称搜索
- 按发布时间自动排序
- 试卷与作业自动分类
- HTML / TXT 文件上传
- 支持直接粘贴 HTML 内容
- 自动生成资料访问 Key
- JSON 文件保存资料索引
- 资料删除
- 答案页面展示
- 分享链接复制
- 基础访问限制机制
- 基于 Cookie 的访问状态控制
- 无数据库运行
- 支持传统 PHP 网站环境直接部署

## 技术栈

| 技术 | 用途 |
| --- | --- |
| HTML5 | 页面结构 |
| CSS3 | 页面样式与响应式布局 |
| JavaScript | 页面交互、搜索、资料加载、分享等 |
| PHP | 文件上传、资料管理、服务端逻辑 |
| JSON | 资料索引与数据存储 |

项目没有使用 React、Vue、Node.js 等大型运行时，部署时只需要一个能够运行 PHP 的 Web 服务器。

## 环境要求

建议使用：

- PHP 7.4+
- PHP 8.x
- Nginx / Apache
- 支持文件写入权限的 PHP 运行环境

项目不需要 MySQL、Redis 或其他数据库服务。

## 部署

将项目文件上传至服务器网站根目录，例如：

```text
/www/wwwroot/your-domain/
```

然后确保 PHP 网站能够正常运行。

同时需要保证以下目录具有 PHP 写入权限：

```text
file/
file/exam/
file/homework/
```

首次使用时，如果 `file/all.json` 不存在，可以创建一个空 JSON 数组：

```json
[]
```

完成后访问网站首页即可。

## 资料上传

项目支持两种资料输入方式：

1. 上传 `.html` 或 `.txt` 文件
2. 直接粘贴 HTML 内容

系统会尝试根据 HTML 内容自动判断资料属于：

- `exam`：考试 / 试卷
- `homework`：作业

如果无法自动判断，可以在上传时手动指定类型。

上传成功后，系统会：

1. 生成随机 Key；
2. 将 HTML 保存到对应目录；
3. 将资料名称、类型、时间和 Key 写入 `file/all.json`；
4. 在首页资料列表中显示。

## 数据格式

`file/all.json` 使用类似以下结构：

```json
[
    {
        "t": 1725000000,
        "type": "exam",
        "name": "示例试卷",
        "background": "none",
        "key": "example123456"
    }
]
```

字段说明：

| 字段 | 说明 |
| --- | --- |
| `t` | Unix 时间戳 |
| `type` | 资料类型，`exam` 或 `homework` |
| `name` | 资料名称 |
| `background` | 列表封面背景 |
| `key` | 资料唯一访问 Key |

## 安全说明

本项目定位为轻量学习资料展示系统，并不是完整的商业级文件管理系统。

如果准备将项目部署到公网，建议根据实际使用场景进一步完善：

- 上传权限控制
- 管理员身份认证
- CSRF 防护
- 上传内容安全检查
- 文件大小限制
- MIME 类型校验
- PHP 文件执行隔离
- Nginx / Apache 目录访问控制
- 日志与异常处理
- 防止恶意 HTML / JavaScript 注入
- 对 `file/` 目录进行合理的访问权限配置

尤其需要注意：项目允许上传 HTML 内容，因此在公网环境中使用时，应谨慎处理上传内容，避免将不可信 HTML 当作普通静态页面直接提供给其他用户访问。
